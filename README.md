Project Description:

This project is a console-based CGPA Calculator developed using C++. It calculates semester GPA using course grade points and credit hours.

Features:
1. Accepts the number of courses.
2. Takes course names, grade points, and credit hours.
3. Calculates total credits and total grade points.
4. Displays individual course details.
5. Displays semester GPA and overall CGPA.
6. Validates basic input values.

Technologies Used:
- Programming Language: C++
- Compiler: GCC / MinGW
- IDE: Visual Studio Code

Formula:
GPA = Total Grade Points / Total Credits

How to Run:
1. Open the project folder in VS Code.
2. Open the terminal.
3. Compile using: g++ cgpa_calculator.cpp -o cgpa
4. Run on Windows using: .\cgpa.exe

Conclusion:
This project demonstrates the use of loops, arrays, conditional statements, input/output operations, and arithmetic calculations in C++.
